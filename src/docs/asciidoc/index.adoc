[[Overview]]
== 📜개요
본 문서는 화장품 도메인 특수성을 반영한 WMS(창고 관리 시스템)의 REST API 명세서입니다.
모든 API는 성공 시 200 OK 또는 201 Created와 함께 JSON 포맷의 데이터를 반환합니다.

[[Member-API]]
== 👤 회원(사원) 도메인 API

=== 2.1 회원 가입 API
새로운 WMS 작업자 또는 관리자를 시스템에 등록합니다.
필수 제약 조건(ID 글자 수, 비밀번호 포맷 등)을 위반하거나 이미 존재하는 ID일 경우 `400 Bad Request`가 발생합니다.
